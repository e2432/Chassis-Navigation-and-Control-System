## 3. 定稿参数要点

**共享执行层**（三基线 + 未来 MPC 同等生效，见 §2 常量）：

```
controller_server ─/cmd_vel_raw─▶ flat_speed_limiter ─/cmd_vel_limited─▶
    safety_supervisor ─/cmd_vel─▶ 底盘
√(vx²+vy²) ≤ 0.6 m/s，|wz| ≤ 1.5 rad/s，加速度 1.0/1.0/2.0，控制 20 Hz
到达判定 0.25 m / 0.25 rad（`general_goal_checker`），progress_checker 0.5 m / 10 s，
`failure_tolerance: 0.5`
```

**代价地图（共享，已知地图口径）**：全局 40×40 m / 0.05 m，原点 −20；局部 6×6 m 滚动；
八边形 footprint（0.3215/0.113/0.328）；`inflation_radius 0.55`、`cost_scaling_factor 3.0`、
`footprint_padding 0.02`；**全局与局部都加载清单几何 `static_layer`**（`nav2_map_server` 发布 `/map`），
全局层点云 `clearing: false`、局部层 `clearing: true`。

## 6. 正式采集口径

- **规模**：3 基线 × 5 场景 × 20 种子 = **300 run**（`run=1..20`，seed = 场景序号×100+run）；
- **命令**：`scripts/run_workset.py --out out/9-2_official --baselines dwa,mppi,teb --runs 1..20`；
- **工作集（种子 1..5）与正式集重合**：这是 9-1/9-2 既定设计（前 5 个种子既用于调参也计入正式 20），
  正式成绩**一律以本次采集重新生成的 `run.json` 为准**，不得引用调参期的任何数字；
- 失败 run **如实保留**（`metrics.success=false` + `failure_class`），不做剔除；
- 每个 run 落 `run.json`（含 `params.m2_diag`：单栈计数、场景身份校验、复位偏移、重规划次数、安全层状态）
  与 `trajectory.npz`；
- 采集中若发现基础设施作废（栈未就绪/规划器偶发失败），脚本自动整场景重试，**不产生伪造数据**。
