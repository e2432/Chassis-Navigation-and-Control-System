## 4. 关键设计事实（已读代码确认，续跑勿再摸索）

### 4.1 数据流与改动面

```
run_w2.sh / run_w3.sh
└─ run_sim.py / run_w3.py（argparse；消融 --no-* → MPCConfig）
   └─ sim.run(scenario, chassis, cfg)   # 0.05 s 控制拍
      ① obs_now ← 场景障碍 t 时刻状态（vo/esdf 消融在此过滤，真值裁判不过滤）
      ② MPCSolver.solve(z, obs_now, ref, t)   # SQP×2 → condensed QP → OSQP
      ③ 细步积分 dt_sim=0.01（真值间隙、路径长度）
      ④ 到达判定 0.25/0.25 → break
      └─ RunResult → runlog.write_run() + plot_run()
```
