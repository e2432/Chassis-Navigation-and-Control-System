## 0. 符号与约定

| 符号 | 含义 | 单位 |
|---|---|---|
| z = [x, y, θ]ᵀ | 位姿（odom/局部规划帧；W2 sim 单帧） | m, m, rad |
| u = [v_x, v_y, ω]ᵀ | 机体系速度（对应 `/cmd_vel` 的 `linear.x/linear.y/angular.z`） | m/s, m/s, rad/s |
| dt | 控制步长 = 0.05 s（契约 20 Hz 定死） | s |
| N | 预测时域步数（初值 40，视界 2 s） | — |
| k = 0..N | 预测步索引；u_k 作用于 [t_k, t_{k+1}) | — |
| z_ref,k | 时变参考位姿 x_ref(t_k) | — |
| s_{k,j} | 第 k 步对障碍 j 的 slack（软约束松弛） | m |
| r_r | 底盘外接圆半径（底盘 YAML `footprint.radius`） | m |
| r_j | 障碍 j 半径（`ObstacleState.radius`，单圆近似） | m |

单位全 SI；角度误差一律 wrap 到 (−π, π]。

## 1. 运动学模型（全向）

连续模型（机体系速度 → 世界系位姿）：

```
ẋ = v_x cos θ − v_y sin θ
ẏ = v_x sin θ + v_y cos θ
θ̇ = ω
```

零阶保持离散化（控制步长 dt）：

```
z_{k+1} = f(z_k, u_k):
  x_{k+1}   = x_k + (v_x,k cos θ_k − v_y,k sin θ_k) · dt
  y_{k+1}   = y_k + (v_x,k sin θ_k + v_y,k cos θ_k) · dt
  θ_{k+1}   = θ_k + ω_k · dt
```

差速轮（迁移冒烟第二模型）不改本模型，只把 `v_y` 的 box 约束收紧为 0（`vy_max = 0`，见 §6），代价中 `v_y` 项自动失效 —— 这是「可迁移性」零代码改动的数学落点。

### 1.1 QP 用线性化（LTV）

模型对 (z, u) 非线性（θ 与 v 双线性）。QP 一步成形需要 LTV 近似：在名义序列 (z̄_k, ū_k) 处一阶展开（§8 SQP 迭代决定名义序列）：

```
z_{k+1} ≈ A_k z_k + B_k u_k + c_k

A_k = [[1, 0, (−v̄_x sin θ̄ − v̄_y cos θ̄) dt],
       [0, 1, ( v̄_x cos θ̄ − v̄_y sin θ̄) dt],
       [0, 0, 1]]

B_k = [[cos θ̄ · dt, −sin θ̄ · dt, 0],
       [sin θ̄ · dt,  cos θ̄ · dt, 0],
       [0,           0,           dt]]

c_k = f(z̄_k, ū_k) − A_k z̄_k − B_k ū_k        （仿射补偿项）
```

## 2. 时变参考（时间律推进 + 目标截断）

参考为时变序列 z_ref,k（k = 0..N），x_ref(t_k) 由**时间律推进**（决策「MPC QP 构造」：参考为时变参考 x_ref(t_k)（k=0..N，按当前进度推进））：

1. 参考几何：**折线路径**（场景脚本 waypoints，W2 起到 NavFn 全局路径的替身；W3~4 换真 NavFn 输出，公式不变）。静态绕行的几何由参考路径承担（与 ADR-0001 分工一致：全局规划管静态路由，局部控制器管跟踪 + 障碍余量 + 动态避让）。
   **不用直参考穿障**：q_long ≤ 0.1·q_lat 时，绕障横向代价压过沿程收益（1 m 横向 ≈ 3.2 m 沿程的代价当量），直参考 + 弱沿程权重会收敛到「停在障碍前」的短视最优——这正是「宁可迟到不可贴障」的另一面；绕障几何必须由全局层给出。
2. 时间律：路径弧长 s(t) = min(v_ref · t, s_goal)，t 为**绝对时刻**（任务时钟）；每拍取 z_ref,k = pose(s(t_now + k·dt))。落后的沿程差由 e_long 吸收，不逐拍重新锚定到机器人投影（重新锚定会让 e_long 只看一步以远，同样陷入停等）。
3. **目标截断**：s(t) 到达终点后，z_ref,k 钉在目标位姿（含目标航向）；此后的 e_long / e_lat 以目标为参考点。不设硬终端约束集（决策「MPC 终端处理」）。
4. 参考航向 θ_ref,k：沿参考线方向；截断段取目标航向。
5. 前馈参考控制 ū_ref,k：`v_x = v_ref`（机体系，参考航向下）、`v_y = 0`、`ω =` 参考航向变化率（直线参考为 0；截断后 ū_ref = 0）。仅用于 LTV 名义序列，不进误差定义。

`v_ref` 初值 0.6 m/s（≤ YAML `v_max`）。

## 3. 误差定义（横向 / 沿程 / 航向）

对 k = 0..N，令位置误差 (Δx, Δy) = (x − x_ref, y − y_ref)：

```
e_long =  Δx · cos θ_ref + Δy · sin θ_ref     （沿程）
e_lat  = −Δx · sin θ_ref + Δy · cos θ_ref     （横向）
e_θ    = wrap(θ − θ_ref)                       （航向）
```

写成矩阵：`e_k = M_k (z_k − z_ref,k)`，

```
M_k = [[−sin θ_ref,  cos θ_ref, 0],
       [ cos θ_ref,  sin θ_ref, 0],
       [ 0,          0,         1]]     （行序：e_lat, e_long, e_θ）
```

## 4. 代价函数（七项标准栈）

对角权重（无交叉项）。阶段代价 k = 0..N−1，终端代价 k = N：

```
J = Σ_{k=0}^{N−1} [ q_lat·e_lat,k² + q_long·e_long,k² + q_θ·e_θ,k²
                  + u_kᵀ R u_k
                  + Δu_kᵀ R_Δ Δu_k
                  + ρ · Σ_j s_{k,j} ]
  + q_lat,T·e_lat,N² + q_long,T·e_long,N² + q_θ,T·e_θ,N²
```

| # | 项 | 权重符号 | 约束（决策） | W2 初值 |
|---|---|---|---|---|
| 1 | 横向误差 | q_lat | — | 4.0 |
| 2 | 沿程误差 | q_long | q_long ≤ 0.1·q_lat | 0.4（= 0.1·q_lat） |
| 3 | 航向误差 | q_θ | — | 1.5 |
| 4 | 控制能量 | R = diag(r_v, r_v, r_ω) | 对角 | diag(0.05, 0.05, 0.02) |
| 5 | 控制增量 | R_Δ = diag(r_dv, r_dv, r_dω) | 对角 | diag(0.20, 0.20, 0.10) |
| 6 | 障碍 slack | ρ（L1 线性罚） | 大权重；静/动共档起步 | 80 |
| 7 | 终端代价 | Q_T = diag(q_lat,T, q_long,T, q_θ,T) | ≥ 2× 阶段对应项；仅位置+航向 | 2× = diag(8.0, 0.8, 3.0) |

说明：

- **沿程显著低于横向**（q_long ≤ 0.1·q_lat）：横向误差是绕障质量的直接代理，沿程误差只负责进度跟踪，权重过高会与障碍软约束抢方向（宁可迟到不可贴障）。
- **控制能量** uᵀR u（不是 (u−u_ref)ᵀR(u−u_ref)）：经典能量项，量级经 R 压低，保证进度由 e_long 项驱动时不被能量项饿死（W2 数值验证）。
- **控制增量** Δu_k = u_k − u_{k−1}（u_{−1} = 上一拍实发控制）：平滑性直接对齐指标 4「平滑度 = 归一化控制量总变差」。
- **slack L1**（不是 L2）：线性罚不放大单次大违反的梯度、不给 QP 加非光滑二次项；配合大 ρ 让违反只在几何上无解时发生。
- 数值为 W2 调参结果（§10 参数表为准，本表随调参更新）。

## 5. 障碍约束（一律软约束）

**共同形式**：每预测步 × 每障碍一条软约束 + 非负 slack：

```
d_j(p_k, t_k) ≥ d_safe − s_{k,j},   s_{k,j} ≥ 0
```

其中 `d_j(p, t) = ‖p − p_j(t)‖ − (r_j + r_r)` 为**外缘间隙**（底盘外缘到障碍面），`d_safe` 为软目标间隙（W2 初值 0.20 m）。安全急停层（0.15 m 硬停）是部署期兜底，不在本 QP 内（决策「安全机制」）。

线性化（在 SQP 名义预测位姿 p̂_k 处）：

```
d_j(p̂_k, t_k) + ∇d_j(p̂_k, t_k)ᵀ (p_k − p̂_k) ≥ d_safe − s_{k,j}
```

对每个 k、j 展开成 U 与 s 的线性不等式（§7 condense）。W2 起静/动**共档**（同一 ρ、同一 d_safe）；拆档触发条件见方案书「MPC slack 拆档」。

### 5.1 静态障碍：ESDF 距离场约束

- 部署形态：costmap 局部窗口一次距离变换得栅格 EDT（ESDF），查询 d 与 ∇d（W5~6；一阶双线性插值 + 数值梯度）。
- W2 调参形态：**解析距离场**（圆近似障碍）：

```
d_j(p)     = ‖p − c_j‖ − (r_j + r_r)
∇d_j(p)   = (p − c_j) / ‖p − c_j‖          （解析梯度，调参纯净）
```

- 非验收 EDT sanity 小脚本（scipy EDT + 有限差分梯度）为 W5~6 排雷：验证栅格 EDT 梯度方向与解析梯度一致，**不进 W2 验收**（决策「W2 距离场」）。

### 5.2 动态障碍：速度障碍 + 匀速直线短期预测（推导）

**输入**：障碍状态列表（契约 `/mpc/obstacles`，`ObstacleState{id, position, velocity, radius}`，odom 帧）。开发期合成状态 = 场景脚本数据；打分通路必须是跟踪器输出（ADR-0003）。

**(a) 匀速直线短期预测**（视界内，t ∈ [0, N·dt]）：

```
p_j(t) = p_j⁰ + v_j · t
```

v_j 来自点云帧间跟踪（或开发期合成）；超出 2 s 视界的非匀速行为不建模，由软约束余量 + 安全急停层兜底。

**(b) 速度障碍（VO）锥**：会与障碍未来位置发生碰撞的相对速度集合：

```
VO_j = { v | ∃ τ > 0: ‖ (p + v·τ) − (p_j⁰ + v_j·τ) ‖ < r_j + r_r }
     = { v | v − v_j ∈ Cone(p_j⁰ − p, r_j + r_r) }
```

即相对速度落进以视线方向为轴、张角由合成半径决定的圆锥。VO 是**速度空间**的非凸锥，直接进 QP 不可行。

**(c) 轨道空间等价（VO 管道）**：把 τ 离散到预测步 t_k，锥的时间并集变成构型空间的**管道**：

```
p_robot(t_k) ∉ B( p_j⁰ + v_j·t_k , r_j + r_r + d_safe ),   k = 1..N
```

沿整个视界停留在每个时间切片的膨胀圆盘之外 ⇔ 未来速度序列不产生 VO 意义上的碰撞。这就是**时域离散 VO 避让**，与静态 ESDF 约束同形（静态是 v_j = 0 的特例，管道退化为静止膨胀圆盘的直积）。

**(d) QP 形式**：对管道约束一阶展开（§5 共同形式），预测中心随 k 移动：

```
p_j(t_k) = p_j⁰ + v_j·(k·dt)        （代入 d_j(·, t_k) 与 ∇d_j(·, t_k)）
```

**实现口径**：动态障碍与静态障碍共用距离约束代码路径，数据源不同——静态查距离场、动态用 (p_j⁰ + v_j t_k, r_j)；W2 两者都是解析式，W5~6 静态换 costmap EDT、动态保持状态列表预测。VO 锥的相对速度半平面线性化（对 v 的约束）备选方案不采用：管道形式能复用距离场机制、静/动统一、且天然带时序（先减速后绕行由视界内各步约束联合表达）。

## 6. limits 约束（box / 线性，运行时读底盘 YAML）

底盘参数化描述（契约 schema）运行时载入，全部进 QP：

```yaml
chassis:
  type: omni                  # omni | mecanum | diff
  footprint: { radius: 0.30 }
  limits:
    v_max: 1.0                # m/s
    v_min: -1.0
    vy_max: 1.0
    omega_max: 1.5            # rad/s
    acc_max: 1.0              # m/s²
    alpha_max: 2.0            # rad/s²
```

| 约束 | 形式 | 来源 |
|---|---|---|
| `v_min ≤ v_x,k ≤ v_max` | box | limits |
| `−v_y_max ≤ v_y,k ≤ v_y_max` | box | limits；**`type: diff` → `vy_max = 0`** |
| `−ω_max ≤ ω,k ≤ ω_max` | box | limits |
| `\|Δv_x\| ≤ acc_max·dt`、`\|Δv_y\| ≤ acc_max·dt` | 线性（增量界） | acc_max |
| `\|Δω\| ≤ alpha_max·dt` | 线性（增量界） | alpha_max |

`type` 不进算法代码：`diff` 只体现为 `vy_max = 0`，迁移冒烟零改动在此兑现。

## 7. QP 标准型（condensed，OSQP）

决策变量 `x = [U; S]`，`U = [u₀; …; u_{N−1}] ∈ R^{3N}`，`S = [s_{k,j}] ∈ R^{N·n_obs}`（n_obs = 障碍数）。

**状态 condense**（消去 z）：`z_k = F_k z₀ + G_k U + h_k`（由 LTV 递推累积 A、B、c），故 `e_k = M_k G_k U + M_k(F_k z₀ + h_k − z_ref,k)`。

**目标**（OSQP：min ½ xᵀ P x + qᵀ x）：

```
P = blkdiag( P_U , 0 )          P_U = 2·Σ_k (M_k G_k)ᵀ Q_k (M_k G_k) + 能量/增量二次项
q = [ q_U ; ρ·1 ]               q_U = 2·Σ_k (M_k G_k)ᵀ Q_k·(M_k(F_k z₀ + h_k − z_ref,k)) + 增量项线性部分
```

（Q_k = diag(q_lat, q_long, q_θ)，k < N 取阶段、k = N 取 Q_T；实现按展开式直接装配，注意 OSQP 的 ½ 因子。）

**约束**（l ≤ A x ≤ u）：

1. 控制 box：u_min ≤ u_k ≤ u_max
2. 增量界：−Δu_max ≤ u_k − u_{k−1} ≤ Δu_max（u_{−1} = 上一拍实发）
3. 障碍：∇d_{k,j}ᵀ p_k + s_{k,j} ≥ d_{k,j} 线性化右端（p_k 是 U 的仿射函数）
4. slack 非负：s_{k,j} ≥ 0

规模（N = 40，n_obs = 2）：变量 3·40 + 40·2 = 200；约束约 3·40（box）+ 3·40（增量）+ 40·2（障碍）+ 80（slack）= 360 行。逐拍求解毫秒级。

## 8. 求解、SQP 迭代与回退

**每控制拍流程**：

1. 名义序列初始化：z̄ = 参考序列，ū = ū_ref（后续拍用上一拍解 shift 热启动）。
2. **SQP 迭代 2 次**（W2 固定）：按名义序列线性化 A_k/B_k/c_k 与障碍梯度 ∇d（在 p̂_k 处）→ 装配 QP → OSQP 求解 → 用解 rollout 出新名义序列。
   （梯度在障碍正中心奇异时取上一拍方向或固定轴向，‖p−c‖ < 1e−6 保护。）
3. 取 u₀ 下发（模拟中喂完美运动学模型）。

**回退（决策「求解器回退」）**：

- OSQP 非 `solved`（含 `primal infeasible` / `max_iter`）→ 本拍发**零速** u = 0，记日志（拍号、状态、障碍数）。
- 下一拍照常重试（不沿用失败解）。
- 连续 **5 拍（0.25 s）**失败 → 报警标志（日志 + 计数；部署期可映射到诊断话题）。
- **不切换第二控制器**。

自包含滚动推演（不接 ROS/Isaac；闭环于完美运动学模型；障碍为场景脚本数据）。W2 到达判定复用指标定义：位置 ≤ 0.25 m 且航向 ≤ 0.25 rad。

**验收四条**（每场景 S1/S2/S3 全过）：

| # | 判据 | 口径 |
|---|---|---|
| ① | 一条命令跑通 | `prototype/mpc_numpy/run_w2.sh`（conda `pro` 环境）退出码 0 |
| ② | 逐步求解成功 | 每个控制拍 OSQP `solved`，回退（零速）次数 = 0 |
| ③ | 推演全程间隙 > 0 | min_t d_j(真值位姿, 障碍) > 0（外缘间隙，含动态障碍预测位置真值） |
| ④ | Δu 总变差有界 | TV = Σ‖Δv‖/v_max + \|Δω\|/ω_max（20 Hz 控制序列）有限，且 TV / n拍 < 0.30（无抖振） |
