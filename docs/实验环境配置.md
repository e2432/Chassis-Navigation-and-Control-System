## 1. 系统与硬件

- **OS**：Ubuntu 22.04（ROS 2 Humble 的官方支持平台）。本机实测 22.04.5，内核 6.8.0-138-generic。
- **CPU**：W4 的瓶颈是 OSQP 单线程求解；24 核对本实验不是硬需求，但批量跑建议至少 4 核。
- **内存**：本机 15 GiB；单条 run 内存占用很低，15 GiB 足够。**不要**无界并行多条 ROS 规划栈（节点名/域会冲突）。
- **磁盘**：仓库 + 100 条实例的 `out/`（maps/logs/runs）约数百 MB；Isaac Sim 一套约 20 GB。本机余 175 GB。
- **GPU/显示**：W4 不需要 GPU、不需要 X11/DISPLAY（matplotlib 使用 Agg，headless 可跑）；Isaac 侧才需要 RTX GPU 与显示/EGL 能力。

## 2. Python 数值环境（conda `pro`，硬规矩）

### 2.1 为什么必须用 `pro`

数值链路（MPC/QP/sim/指标/出图）**只在 conda `pro`**。本机实测版本：

| 包 | 版本 |
|---|---|
| Python | 3.11.15 |
| numpy | 1.26.0 |
| scipy | 1.15.3 |
| osqp | 0.6.7.post3 |
| matplotlib | 3.10.3 |
| PyYAML | 6.0.2 |

> 这些是 W2/W3 验证过的版本；其它版本未做回归。`osqp` 的 Python 包版本必须与数值链路一致。

### 2.2 两种等价用法（推荐 A）

```bash
# A. 直接用 pro 的 Python 绝对路径（脚本/run_w2.sh/run_w3.sh 都按这个写）
PY=/home/robot/miniconda3/envs/pro/bin/python
$PY -c "import numpy, scipy, osqp, matplotlib, yaml; print('env ok')"

# B. 激活 conda 环境
source ~/miniconda3/etc/profile.d/conda.sh
conda activate pro
python -c "import numpy, scipy, osqp; print('env ok')"
```

### 2.3 解释器陷阱（本机实测）

- 当前 shell 的 `CONDA_DEFAULT_ENV=base`；`python` / `python3` 解析到 **conda base 3.13.9**，不是系统 3.10，也没有 osqp。
- 系统 `python3` 是 `/usr/bin/python3` 3.10.12；conda base 会抢 PATH。
- **结论**：不要依赖裸 `python3`。数值链路用 pro 绝对路径；取源壳用 `/usr/bin/python3`；两者不要混。

### 2.4 新机器复现（最小数值环境）

```bash
conda create -n pro python=3.11 -y
conda run -n pro pip install \
  "numpy==1.26.0" "scipy==1.15.3" "osqp==0.6.7.post3" \
  "matplotlib==3.10.3" "pyyaml==6.0.2"
```

> W4 不要求 pro 内安装 Isaac Sim；本机 pro 内另有 `isaacsim 5.1.0.0` 与 IsaacLab，属于可选的仿真/基准套件环境，**数值推演不要 import**。

## 3. ROS 2 Humble + Nav2（仅 NavFn 参考需要）

### 3.1 版本与安装

> 前置：系统已按 ROS 2 Humble 官方文档配置 apt 源并安装 Humble；本节只补 Nav2 与 tf2_ros（本机已装好）。

本机实测：

| 包 | 版本 |
|---|---|
| ROS 发行版 | Humble（`/opt/ros/humble`） |
| `ros-humble-navigation2` | 1.1.20 |
| `ros-humble-nav2-map-server` / `nav2-planner` / `nav2-msgs` | 1.1.20 |
| `ros-humble-rclpy` | 3.3.21（系统 Python 3.10.12） |
| `ros-humble-tf2-ros` | 0.25.20 |
| `ros-humble-ros2cli` | 0.18.18 |

一次性安装（需 sudo）：

```bash
sudo apt-get update
sudo apt-get install -y ros-humble-navigation2 ros-humble-tf2-ros
# 中文出图（若缺字体）
sudo apt-get install -y fonts-noto-cjk
```

> `run_w3.sh` 会检查 `ros2 pkg executables nav2_map_server`；缺失时提示安装 `ros-humble-navigation2`。

### 3.2 双 Python 分工（刻意设计，不是偷懒）

| 环境 | 跑什么 | 原因 |
|---|---|---|
| conda `pro`（3.11） | 地图栅格化、MPC/QP（osqp）、sim 推演、验收、出图 | W2 验证过的数值栈 |
| `/usr/bin/python3`（3.10） | `mpc_proto/navfn_source.py` 取源壳（零数学） | Humble rclpy 是 CPython 3.10 C 扩展，pro 3.11 ABI 不通 |

**禁止**在 conda 侧 `import rclpy`；取源壳由 `run_w3.py` 以 subprocess 调 `/usr/bin/python3`。撞墙的解法是拆进程，不是换数值环境。

### 3.3 验证

```bash
source /opt/ros/humble/setup.bash
echo "$ROS_DISTRO"                              # humble
ros2 pkg executables nav2_map_server            # map_server
ros2 pkg executables nav2_planner               # planner_server
ros2 pkg executables tf2_ros | head              # static_transform_publisher 等
/usr/bin/python3 -c "import rclpy; print(rclpy.__file__)"
```

## 4. 环境变量

| 变量 | 建议值 | 设置位置 | 用途 |
|---|---|---|---|
| `ROS_DOMAIN_ID` | `42` | `run_w3.sh` / `run_w4.sh` / 手动命令 | 隔离本机其它 ROS 图 |
| `PYTHONUNBUFFERED` | `1` | 批量跑时 export | 后台日志逐行可见 |
| `NAV_WS` | 仓库根目录（可选） | 手动 export | 实例表不在默认仓库相对路径时指定 |
| `ROS_DISTRO` | `humble` | `source /opt/ros/humble/setup.bash` 后自动 | ROS 环境 |
| `DISPLAY` | 不需要 | — | W4 用 Agg；RViz/Isaac 才需要 |

> 调试终端也要 `export ROS_DOMAIN_ID=42`，否则 `ros2 node list` 看不到脚本拉起的节点。
> `NAV_WS` 只在需要覆盖实例表路径时设置；默认加载器按仓库相对路径找 `docs/scenarios/instances.yaml`。

## 6. 运行入口

### 6.1 W2（无 ROS，纯数值）

```bash

```

### 6.2 W3（NavFn 参考，S1~S3 回归）

```bash
cd prototype/mpc_numpy
```

### 6.3 W4 实例

`run_w4.sh` 是 W4 入口（ROS 环境 + 静态 TF + 清理）；实例模式自动使用
`nav2_w4_params.yaml`（inflation 0.60 / cost_scaling 5.0），W3 的 S1~S3 仍用
`nav2_w3_params.yaml`（0.35 / 3.0），互不影响。

```bash
cd prototype/mpc_numpy
# 单实例端到端
./run_w4.sh --instance static_avoid:1 --no-plot --quiet
# 调参工作集（5 场景 × 前 5；独立目录，不进判读）
./run_w4.sh --suite --runs 1-5 --out out/tuning/roundN --no-plot --quiet
# 全 20（判读数据）
./run_w4.sh --suite --runs all --out out --no-plot --quiet
# 只取 NavFn 路径做 100 条可行性扫描（不推演/不落 run）
./run_w4.sh --suite --runs all --map-only --quiet
```

手动等价命令（不推荐，便于调试）：source ROS、`export ROS_DOMAIN_ID=42`、后台起
`tf2_ros static_transform_publisher`（map→base_link），再执行
`$PY run_w3.py --instance ...`；退出时 `pkill -f '[n]av2_map_server'`、
`pkill -f '[n]av2_planner'`。`run_w4.sh` 已封装这些步骤。

> W4 的**判读数据必须走 NavFn 参考**（`run_w4.sh` / `run_w3.py` 实例模式），不是
> `run_sim.py --instance` 的直线参考；后者只作管线冒烟/调试。
> 加载器验收与汇总：`$PY check_instances.py`、`$PY summarize_runs.py --runs-root out/runs --expected 20 --check`。

## 8. 可选：Isaac Sim / nav_ws_core 基准套件

**W4 离线实验不需要本节**；只有走 Isaac 基准套件/工程侧建图时才需要。

- **Isaac Sim**：本机 conda `pro` 内 `isaacsim 5.1.0.0`（ROS 桥接 4.12.4）+ IsaacLab；GPU 为 RTX 4060 Laptop 8 GB，驱动 580.82.07（仅够最小桥接/预览，重场景建议更大显存）。Isaac 侧使用 Python 3.11、Humble 桥接；与 W4 数值链路共用 `pro`，但**不要在同一进程里 import rclpy**。
- **nav_ws_core 构建/预览**（工程侧）：Ubuntu 22.04、ROS 2 Humble、colcon、ament_cmake/ament_python、robot_state_publisher、xacro、rviz2、rclpy、tf2_ros、PyYAML、pytest。本机 `colcon`/`rosdep`/`python3-yaml`/`python3-pytest` 已有；**`xacro` 与 `rviz2` 当前缺失**，如要构建工程侧：

- **场景表生成/校验**：工程侧 `nav_ws_core/src/robot_benchmark`（`gen_scenarios --check`、`pytest`）。W4 只读消费冻结表，不重新生成。

## 9. 常见故障速查

| 现象 | 原因 / 处理 |
|---|---|
| `ModuleNotFoundError: osqp` | 用错解释器（conda base 3.13 或系统 3.10）→ 用 pro 绝对路径，或 `conda activate pro` |
| `ModuleNotFoundError: rclpy`（pro） | 预期行为：Humble rclpy 只支持系统 3.10；取源壳必须 `/usr/bin/python3`，不要在 pro import |
| `ros2: command not found` | 未 source：`source /opt/ros/humble/setup.bash` |
| `ros2 lifecycle set ... Unknown transition` | 有残留同名节点；`pkill -f '[n]av2_map_server'`、`pkill -f '[n]av2_planner'` 后重跑 |
| `get-path` 空路径/超时 | 换图后 StaticLayer 异步竞态；脚本已有界重试 ×5，持续失败查 `out/w3_logs/*_planner.log` |
| 中文标签显示方框 | 缺 `Noto Sans CJK SC`；装 `fonts-noto-cjk` |
| NavFn 找不到路径 | 目标/起点被墙或圆障碍挡住（表内应已校验可达）；检查 `mapping.py` 墙体栅格化与 `nav2_*_params.yaml` inflation |
| NavFn 折线穿过物理间隙 <d_safe、MPC 停滞 | W3 的 inflation 0.35 只是代价；W4 实例用 `nav2_w4_params.yaml`（0.60/5.0）取可行折线 |
| `run_w3.sh` 报「Nav2 未安装」 | 缺 `ros-humble-navigation2`；按 §3.1 安装 |
| 批量跑看不到进度 | 后台重定向时 stdout 块缓冲；`export PYTHONUNBUFFERED=1` |
| 规划栈串图/路径错误 | 本流程逐实例重启规划栈；不要改成单栈 `LoadMap` 换图 |

## 10. 新机器最短复现步骤

```bash

cd Chassis-Navigation-and-Control-System/prototype/mpc_numpy

# 4) 自检（见 §7）
PY=/home/robot/miniconda3/envs/pro/bin/python   # 按本机 conda 路径替换
```
