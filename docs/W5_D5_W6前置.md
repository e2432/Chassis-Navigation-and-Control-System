## 3. W6 接入缺口（按优先级）

1. **完整 Nav2 bringup 缺失**
   - 仓库内没有包含 `controller_server + planner_server + bt_navigator` 的 M2 launch/params；
     现有 `nav2_mpc_params.yaml` 只覆盖 controller/local_costmap。
   - W6 需要复用 M2 交付的 Nav2 启动配置，或新增算法线 W6 launch；**不得改 `robot_*` 包**。
   - 基线参数与 MPC 参数继续分文件，避免互相污染。

2. **路径坐标系变换（已修复 2026-11-13，commit `cc3d005`）**
   - 原缺口：插件保存了 `tf_` 但 `setPlan()` 后直接用 `global_plan_.poses` 与 `pose` 计算，
     **未做 TF 变换**；Nav2 全局路径通常在 `map`，局部 costmap 为 `odom`，非 identity 时会算错。
   - 修复：`setPlan()` 保存原始路径与 `frame_id`；`computeVelocityCommands()` 每拍按当前 TF
     把路径变换到 costmap `odom` 帧后再前视跟随；TF 缺失/超时明确失败并零速，不回退未变换路径。
   - 回归：omni/diff × 恒等/非恒等 `map→odom`、TF 缺失安全停止、TF 超时零速均通过；
     日志本地 `out/w5_tf_regression/`。

3. **局部代价地图传感器源**
   - D3 配置用假 `/scan` + obstacle_layer（`nav2_mpc_params.yaml:55-70`）；W6 应改用
     Isaac `/lidar/points`（PointCloud2、best_effort）配置 obstacle/voxel layer，
     或按 W6 EDT 方案使用空局部 costmap + 算法侧距离场。
   - 需显式给内部 `local_costmap.local_costmap` 设置 `use_sim_time=true`；
     当前参数文件未写，D3 用系统时钟。
   - 验证 `isCurrent()`；必要时保留假 scan 作为测试兜底，但不进正式导航。

4. **仿真时钟与心跳语义复测**
   - 桥接 `/clock` 已存在；W6 所有 Nav2/插件/跟踪器/odom/TF 节点统一 `use_sim_time=true`。
   - D3 只在系统时钟下验证了 0.5 s 心跳超时；W6 必须复测：
     过期 header 不刷新心跳、首条有效消息前零速、停心跳 >0.5 s 告警+零速、恢复心跳后恢复。
   - 仿真暂停时 ROS 时间不前进；ROS 超时只证明仿真时间语义，不替代真机独立安全监控。

5. **真实障碍跟踪器替换 mock**
   - 正式导航禁止 mock 心跳；跟踪器失联时必须停止发布或显式失效，
     **不得持续发布“有效空数组”**（见 `msg/README.md` 的 W6 约束）。
   - 跟踪器消息必须用仿真时间戳、`frame_id=odom`；QoS/频率与插件订阅匹配。

6. **底盘参数与限速一致性**
   - `FollowPath.footprint.radius=0.30` 必须与 local_costmap `robot_radius` 同源；
     `diff → vy_max=0` 保留；速度限制走 controller_server `speed_limit`。
   - 注意 `min_y_velocity_threshold` 过滤的是传给插件的 odom 速度，不是 `/cmd_vel` 输出；
     D3 参数已设 0.0，W6 仍需按全向底盘复核。
   - 保留 D3 的绝对/百分比/NO_SPEED_LIMIT 限速回归。

7. **MPC 求解接入**
   - D4 只更新线性代价 `q`；W6 需处理 `P/A/l/u` 更新、动态障碍数量变化导致约束结构变化，
     以及固定稀疏结构与重新 setup 的策略。
   - `SOLVED_INACCURATE` 单独计数/告警，不默认采用；`PRIMAL_INFEASIBLE`/
     `MAX_ITER_REACHED`/求解失败 → 零速回退 + 连续失败告警。
   - 冷启动、热启动、障碍突变后的耗时分开统计；D4 p95=0.131 ms 不能代表整控制周期。
   - 将 D4 修复过的速率约束符号错误纳入 Python/C++ 约束矩阵逐项回归。

## 4. Isaac 可用时的运行核对清单（W6 执行）

```bash
# 仿真
ros2 launch robot_bringup simulation.launch.py use_sim_time:=true

# 时钟/里程计/点云
ros2 topic hz /clock
ros2 topic echo /clock --once
ros2 topic hz /odom
ros2 topic hz /lidar/points
ros2 topic info -v /lidar/points          # best_effort QoS 确认

# TF 单源与树
ros2 run tf2_ros tf2_echo map base_footprint
ros2 run tf2_ros tf2_echo odom base_footprint
ros2 run tf2_ros tf2_echo map odom
ros2 topic echo /tf_static --once

# Nav2/插件
ros2 lifecycle get /controller_server
ros2 param get /controller_server FollowPath.type
ros2 param get /controller_server FollowPath.footprint.radius
ros2 param get /local_costmap/local_costmap use_sim_time
ros2 action list | grep follow_path

# 发送 2 m 假路径，检查 /cmd_vel；再停跟踪器 >0.5 s 检查告警与零速
```
