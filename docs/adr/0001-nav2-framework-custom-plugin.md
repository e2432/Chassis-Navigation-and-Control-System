# 导航算法路线：Nav2 框架 + 自研局部控制器插件

---
status: accepted
---

为同时满足避障算法「优越性」（需可量化的基准对比）与「可迁移性」（Sim2Real + 平台无关，定义见 GLOSSARY.md）两项验收标准，决定复用 Nav2 的 costmap、行为树、tf 等基础设施，仅自研局部控制器插件（MPC 或基于优化的方法），全局规划沿用 Nav2 现成插件。

**Considered Options**
- 完全自研全链路：放弃——约 60% 工期将消耗在重造 costmap/tf 上，且无标准基线，「优越性」无法量化证明。
- 纯现成（DWA/TEB/MPPI 调参）：放弃——无创新点，不符合项目定位。
- Nav2 + 自研插件：采纳——标准接口保证可迁移性；Nav2 自带 DWA/TEB/MPPI 构成现成对照基线；自研焦点集中在避障创新所在的局部层。
