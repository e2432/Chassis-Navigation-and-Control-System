# 感知传感器选型：3D 激光雷达 Livox Mid-360

---
status: accepted
---

感知层选 3D 固态激光雷达 Livox Mid-360，而非 2D 激光雷达。理由：全向底盘 + 动态复杂场景的避障需要完整三维信息（悬空障碍、低矮障碍、行人轮廓），Mid-360 是当前性价比最高的 3D 方案，且与 FAST-LIO2 的适配最成熟。

**Considered Options**
- 2D 雷达（RPLIDAR/镭神）：放弃——成本低、Nav2 适配零障碍，但丢失高度信息，复杂动态场景避障能力受限；且一旦购买 2D，后期升级 3D 意味着重新采购与管线重构。
- Mid-360（3D）：采纳——代价是成本高一个数量级、管线复杂度上升（需 FAST-LIO2、点云→costmap 转换）。
