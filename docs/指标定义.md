# 指标定义（v1.0，W3 定稿 + 2026-10-31 补全）

> W3 定稿（2026-10-30），交搭档实装基准套件指标采集。键名与 docs/接口契约.md 一致。阈值为初值：W4 基线（DWA/TEB/MPPI）入库后按方案书「阈值方法论」校准一次，W7 前冻结、此后只严不松。2026-10-31 /grill-with-docs 补全裁判对象、目标位姿、急停计数口径（见下表与文末补全清单）。

## 公共判定（单 run）

| 判定 | 定义 |
|---|---|
| 目标位姿 | 位置 = 场景目标点（随机化见 docs/5场景需求清单.md）；航向 = 起终点连线方向（行进方向），不随机化（GLOSSARY「目标位姿」） |
| 碰撞 | 真值几何穿透：任一时刻底盘外形与**场景几何**（离散障碍物 + 墙体等环境结构，GLOSSARY「场景几何」）间距 ≤ 0 |
| 到达 | 相对目标位姿：位置误差 ≤ 0.25 m 且航向误差 ≤ 0.25 rad（进入公差即算到达，之后位姿不考核） |
| 时限 | 场景级固定时限，数值见 docs/5场景需求清单.md；校准公式 = 基线中位到达时间 × 1.5，下限 60 s（W4 基线入库后一次回填） |
| 成功 | 无碰撞 ∧ 到达 ∧ 时限内。安全急停层触发可恢复，不判失败 |
| 出发时刻 | 基准脚本注入目标的时刻。控制器始终无有效输出 → run 判超时失败，到达时间记未到达 |

轨迹量一律取自真值定位，不走 SLAM 管线；`/cmd_vel` 重采样到 20 Hz 后参与计算。

## 7 项指标

| # | 指标 | 单 run 定义 | 场景级聚合 | 单位 | 方向 | 阈值（初值） |
|---|---|---|---|---|---|---|
| 1 | 成功率 | 成功 ⟺ 公共判定 | 成功数 / 20 | % | ↑ | ≥ 95% |
| 2 | 到达时间 | 到达 − 出发，仅成功 run | 中位数 | s | ↓ | 对比基线 |
| 3 | 路径长度 | 真值轨迹 Σ‖p_{k+1} − p_k‖，固定步长采样（见说明），仅成功 run | 中位数 | m | ↓ | 对比基线 |
| 4 | 平滑度 | TV = Σ（‖Δv‖ / v_max + \|Δω\| / ω_max），仅成功 run | 中位数 | 无量纲 | ↓ | 对比基线 |
| 5 | 最小间距 | run 内 min_t d(底盘外形, 场景几何) | 20 次中位数（附最坏值） | m | ↑ | ≥ 0.3 |
| 6 | 急停次数 | 安全急停层触发次数（边沿计数：`/safety/stop` 上升沿，一次连续急停过程计 1 次，解除后再触发再计） | 20 次合计 | 次 | ↓ | ≤ 1 |
| 7 | 动态应变 | —（跨场景） | `dynamic_pedestrian` + `mixed` 合并成功率 | % | ↑ | ≥ 90% |

说明：

- **路径长度采样步长**：固定步长 = 真值 `/odom` 输出周期（数值随 M1 落地写死），所有 run、所有基线同一步长；与控制周期解耦，不按控制拍累计。
- 指标 4 的 v_max、ω_max 取自底盘参数化描述文件；总变差对控制频率解耦（先重采样 20 Hz）。
- 指标 5 阈值初值 0.3 m 是质量锚点，不由安全急停层阈值 0.15 m 推导；但校准后阈值不得低于 0.20 m（硬底线 = 急停阈值 0.15 m + 一档 0.05 m，见方案书「阈值方法论」）。
- 指标 7 是指标 1 在动态场景子集上的约束（阈值更低，单独考核动态压力）；成功判定与指标 1 完全一致，不另立定义。
- W4 原型离线成绩中的动态场景为「乐观上界」（合成障碍状态、无跟踪噪声），不作打分定论；打分真口径以 M3 基准（跟踪器在线）为准。

## 指标↔场景映射

| # | 指标 | static_avoid | dynamic_pedestrian | narrow_passage | dead_end | mixed |
|---|---|---|---|---|---|---|
| 1~6 | 全部六项 | ✓ | ✓ | ✓ | ✓ | ✓ |

- 双向覆盖硬验收：每个指标至少覆盖一个场景，每个场景声明产出指标（即上表）；不许悬空指标。
- 指标 7 为套件级字段（合并口径），不进单场景 dict；M4② 逐场景对比只计指标 1~6（方案书验收判据已同步）。
- 场景集合锚定「基准场景套件」（GLOSSARY.md）；增删换场景属术语表级变更，须同步本表。

- [x] **阈值校准**：初值即上表；W4 基线入库后按方案书「阈值方法论」（取硬底线与「最优基线 ± 容差」中更严者）校准一次，此后仅可收紧。

## 2026-10-31 补全口径（/grill-with-docs）

- **裁判对象** = 场景几何（GLOSSARY）：碰撞与最小间距均含墙体等环境结构，不只离散障碍物。
- **目标位姿航向** = 起终点连线方向，不随机化；到达判定的航向误差以此为参考。
- **急停计数** = 边沿计数：`/safety/stop` 每个上升沿计 1 次（一次连续急停过程计 1 次，解除后再触发再计），无防抖合并。
- **阈值硬底线**：最小间距阈值校准后 ≥ 0.20 m（急停阈值 0.15 m + 一档 0.05 m）。
