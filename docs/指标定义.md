# 指标定义（草案 v0.1）

> W1 交付草案；W3 定稿后交搭档实装基准套件。键名与 docs/接口契约.md 一致。阈值均为草案，基线（DWA/TEB/MPPI）实测后校准。

## 公共判定（单 run）

| 判定 | 定义（草案） |
|---|---|
| 碰撞 | 真值几何穿透：任一时刻底盘外形与障碍物间距 ≤ 0 |
| 到达 | 位置误差 ≤ 0.25 m 且航向误差 ≤ 0.25 rad（进入公差即算到达，之后位姿不考核） |
| 时限 | 场景级固定时限，W3 随 5 场景需求清单定稿（建议 = 基线中位到达时间 × 1.5，下限 60 s） |
| 成功 | 无碰撞 ∧ 到达 ∧ 时限内。安全急停层触发可恢复，不判失败 |
| 出发时刻 | 基准脚本注入目标的时刻（W3 定稿备选：控制器首个非零 `/cmd_vel` 时刻） |

轨迹量一律取自真值定位，不走 SLAM 管线；`/cmd_vel` 重采样到 20 Hz 后参与计算。

## 7 项指标

| # | 指标 | 单 run 定义 | 场景级聚合 | 单位 | 方向 | 阈值草案 |
|---|---|---|---|---|---|---|
| 1 | 成功率 | 成功 ⟺ 公共判定 | 成功数 / 20 | % | ↑ | ≥ 95% |
| 2 | 到达时间 | 到达 − 出发，仅成功 run | 中位数 | s | ↓ | 对比基线 |
| 3 | 路径长度 | 真值轨迹 Σ‖p_{k+1} − p_k‖，仅成功 run | 中位数 | m | ↓ | 对比基线 |
| 4 | 平滑度 | TV = Σ（‖Δv‖ / v_max + \|Δω\| / ω_max），仅成功 run | 中位数 | 无量纲 | ↓ | 对比基线 |
| 5 | 最小间距 | run 内 min_t d(底盘外形, 障碍物真值几何) | 20 次中位数（附最坏值） | m | ↑ | ≥ 0.3 |
| 6 | 急停次数 | 安全急停层触发次数 | 20 次合计 | 次 | ↓ | ≤ 1 |
| 7 | 动态应变 | —（跨场景） | `dynamic_pedestrian` + `mixed` 合并成功率 | % | ↑ | ≥ 90% |

说明：

- 指标 4 的 v_max、ω_max 取自底盘参数化描述文件；总变差对控制频率解耦（先重采样 20 Hz）。
- 指标 5 阈值 0.3 m 是质量锚点，与安全急停层硬阈值 0.15 m（外缘距离）无关。
- 指标 7 是指标 1 在动态场景子集上的约束（阈值更低，单独考核动态压力）；成功判定与指标 1 完全一致，不另立定义。
