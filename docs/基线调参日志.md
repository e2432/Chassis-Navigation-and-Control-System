## 4. 统一调参协议

| 轮次 | 动作 | 预算/产出 |
|---|---|---|
| Round 0 | 工程侧按当前 M2 配置 + §2 共同常量跑 25 run | 基线现状；只用于判读，不进入库 |
| Round 1 | 按 §5 每个基线只改**一个参数族**（速度/采样/权重之一），跑 25 run | 与 Round 0 对比；回填模板 |
| Round 2 | 仅当 Round 1 达到「明显改善」才允许；只改另一参数族 | 最多 2 轮；无改善即停 |
| 冻结 | 选定定稿参数，YAML 版本化，写停判理由 | 定稿参数 × 全 20 正式采集 |
| 9-3 时限冻结 | 用定稿参数工作集（或单独 5 种子计时）得到各场景中位到达时间 → 基线中位×1.5、下限 60、mixed 75；**正式 20 采集前冻结** | 一次 PR 留痕；MPC 与三基线同限 |
| 正式采集 | 定稿参数 × 每场景全 20 | 100 run/基线；不得混入调参期 run |

**明显改善**（Round 1 → Round 2 的门槛，需同时满足）：

1. 工作集成功率不低于上一轮，且 ≥95%；
2. 最小间距中位数不低于上一轮，且 ≥0.30 m；
3. 急停合计不高于上一轮，且 ≤1；
4. 动态场景 `dynamic_stress` 不低于上一轮，且 ≥90%；
5. 到达时间中位数改善 ≥5%，或所调目标指标（如最小间距）改善 ≥10% 且到达时间不劣化 >10%；
6. 不得出现任一场景新增失败（5 次中多 1 次失败即 +20pp），或最小间距低于 0.20 m 硬底线。

不满足 → **停**，保留上一轮参数，不进入 Round 2。

**5 种子分辨率说明**：每场景工作集只有 5 run，成功率只能以 **20pp** 步进变化；
聚合 25 run 时 5pp 约等于 1.25 run。上述判停规则（到达时间 5% / 成功率按新增失败）
是**保守安全规则**，不是有足够分辨率的统计结论。Round 1/2 不追求统计显著性；
正式 20 run 才用于 M4 对比。

**禁止**：为单个场景调专属参数；为单个指标牺牲成功率/间距；超过底盘能力上限；
把调参期 run 当正式成绩；改共享 costmap/全局规划器而不告知。

## 6. 指标与判停

七项指标定义见 `docs/指标定义.md`：成功率、到达时间、路径长度、平滑度、最小间距、
急停次数、动态应变。逐场景记录 1~6 项中位数/合计；`dynamic_stress` 为套件级。

**调参期安全门**（每轮必过）：

- 成功率 ≥95%（M4 硬底线 ≥90%，调参用更严值）；
- 最小间距中位数 ≥0.30 m（M4 硬底线 0.20 m）；
- 急停合计 ≤1；
- 动态场景 `dynamic_stress` ≥90%。

**定稿选择**：先满足安全门，再比成功率/到达时间/间距；不以单项最优选参数。
若 2 轮后仍无参数组满足安全门，停止并报告“基线在当前场景/配置下不达标”，
不继续堆参数、不改场景或指标。

**9-3 时限冻结（正式 20 采集前）**：定稿参数后，用定稿工作集（或单独 5 种子计时）
计算各场景基线中位到达时间，按 `max(60, 中位×1.5)`、mixed 下限 75 s 回填并冻结；
MPC 与三基线使用**同一时限、同一实例表、同一裁判规则**。正式采集开始后不得改时限；
若必须改，停止采集、重算并重跑全部受影响官方成绩，不能新旧混用。

**5 种子与正式 20 的分工**：工作集只用于调参判停（并接受 20pp 分辨率限制）；
正式 20 run 才用于 M4 对比与报告，不把工作集成绩混入入库。

## 10. 待确认决定

1. **主对比运动学**：保持 **omni**（原方案）；diff 仅迁移冒烟。若 TEB 实测无法 omni，
   双方另议（换 fork/换基线/另设 diff 辅助比较），不单方面改主实验，也不静默删除 TEB。
2. **任务速度 0.6 m/s**：与 W4 MPC 对齐；若工程侧现有基线已用其他任务速度，先统一再开跑。
3. **TEB 可用性**：源码 fork/commit/插件名；必须通过 §5.3 五项实际验证。不可用则 9-2
   无法凑齐三基线，需上报，不能默认可用或擅自删除。
4. **共享 costmap/规划器**：确认三基线同配置；若 M2 已有差异，先统一。
5. **DWA 即 DWB**：Nav2 的 `dwb_core::DWBLocalPlanner` 作为 DWA 基线；报告须准确注明
   “DWA 基线由 Nav2 DWB 实现”，不写成独立 DWA 实现。
6. **9-3 时限冻结**：必须在正式 20 采集前完成；采集开始后改时限则全部受影响成绩重跑。
