# 5 场景需求清单（W3 定稿）

> W3 交付物，交搭档实装基准套件（M2 场景）。**需求而非设计**：环境要素与量化参数为硬需求，场景布局、资产选型由建造者定。参数一律绝对物理值锚定，不随底盘缩放（迁移冒烟即跑同一批场景）。键名与 docs/接口契约.md、docs/指标定义.md 一致。

## 通用约定

- **场景集**：5 个 scenario 键 `static_avoid | dynamic_pedestrian | narrow_passage | dead_end | mixed`，锚定 GLOSSARY「基准场景套件」，不增不换；变更走术语表级流程（改 GLOSSARY.md 并同步指标↔场景映射）。
- **实例配对**：每场景 20 个随机实例，固定种子表——种子 = 场景键序（1~5，按上行顺序）× 100 + run 序（1~20）。所有被测控制器（自研 + DWA/TEB/MPPI）跑同一实例集，逐 run 配对。
- **时限**：初值见逐场景表；校准公式 = 基线中位到达时间 × 1.5、下限 60 s，W4 基线入库后一次回填（口径见 docs/指标定义.md）。
- **判定口径**：碰撞 / 到达 / 成功 / 出发时刻一律见 docs/指标定义.md，本清单不另立定义。碰撞与间距的裁判对象为场景几何（含墙体等环境结构）。
- **起点与目标航向**：起点位姿固定（起终点连线一端、朝向沿线）；目标位姿航向固定为连线方向（行进方向）。随机化作用于障碍（行人）、目标位置、static_avoid / dynamic_pedestrian 的起终点直线长度（9.5~10.5 m，2026-11-06 契约 v1.3 追认），以及 narrow_passage / dead_end 的布局维度（2026-11-06 契约 v1.4 追认 2.0.0 重冻结，见对应场景行）。另有**世界摆放维度**（契约 v1.4「世界摆放口径」）：逐种子冻结的世界系刚体位姿（`world_poses`），不改 path frame 几何、不属本清单几何抽样。
- **统一验收动作**：参数逐项核对 + 空跑 20 实例可复位、可复现，无需口头补充。清单级验收：搭档据此搭场景无需口头补充、互审通过。

## 逐场景需求

### static_avoid · 静态障碍绕行

| 项 | 内容 |
|---|---|
| 目的—测指标 | 指标 1~6（避障基础：成功率 / 间距 / 平滑度） |
| 环境要素 | 起终点直线 10 m（抽样 9.5~10.5）；静态障碍 4~6 个，半径 0.3~0.6 m，横向偏置 ±1.5 m |
| 随机化范围（20 实例） | 障碍位置 ±0.3 m；障碍个数 4~6 内抽样；障碍半径逐障碍独立抽样 0.3~0.6 m；起终点直线长度 9.5~10.5 m（2026-11-06 v1.3 追认，2.0.0 重冻结沿用同范围） |
| 时限初值 | 60 s |

### dynamic_pedestrian · 动态行人

| 项 | 内容 |
|---|---|
| 目的—测指标 | 指标 1~6；指标 7（动态应变）主场之一 |
| 环境要素 | 起终点直线 10 m（抽样 9.5~10.5）；行人 1~2 个，半径 0.3 m，垂直横穿，横穿路线与行进路线相交于中点 ±2 m；行人运动语义按契约 v1.4 常速横穿——`y = dir·speed·(t−t_meet)`，全程匀速直线、不折返，无延迟启动与停住 |
| 随机化范围（20 实例） | 行人个数 1~2 内抽样；行人速度 0.6~1.0 m/s、相遇时刻 ±2 s（均逐行人独立抽样）；横穿方向（左→右 / 右→左）对称随机；起终点直线长度 9.5~10.5 m（2026-11-06 v1.3 追认，2.0.0 重冻结沿用同范围） |
| 时限初值 | 60 s |

### narrow_passage · 窄通道

| 项 | 内容 |
|---|---|
| 目的—测指标 | 指标 1~6（窄道通过 + 间距保持） |
| 环境要素 | 直线窄通道，长 2.6~4.0 m（2.0.0 布局抽样）；**净宽 1.4±0.1 m**——名义余量 0.4 m/侧 = 指标 5 阈值 0.3 m + 漂移预算 0.1 m，不得窄于 1.3 m；含薄导向墙（`guide_corridor`）与深门洞（`gate_corridor`）两种结构 |
| 随机化范围（20 实例） | 净宽 1.3~1.5 m；通道长 2.6~4.0 m；通道入口位置与横向偏移（通道不必过行进线中点）；壁厚；结构 kind（薄导向墙 / 深门洞）；起终点直线长度随布局 10.5~12.7 m（布局维度 2026-11-06 契约 v1.4 追认 2.0.0 重冻结生成，此前「通道端点 ±0.3 m」授权作废） |
| 时限初值 | 60 s |

### dead_end · 死角

| 项 | 内容 |
|---|---|
| 目的—测指标 | 指标 1~6（陷阱规避或入库恢复，必要时倒车） |
| 环境要素 | U 形盲袋：袋口净宽 1.4±0.1 m、袋深 1.9~3.2 m（2.0.0 布局抽样）；**目标在陷阱外**（袋口背向侧），任务允许规划绕行或入库后倒车恢复，不宣称必须入库倒车（2026-11-06 契约 v1.4 认领新语义） |
| 随机化范围（20 实例） | 袋口净宽 1.3~1.5 m；袋深 1.9~3.2 m；袋口朝向（西/东/南/北四向对称）；袋位与壁厚；起终点直线长度随布局 10.5~12.5 m（布局维度 2026-11-06 契约 v1.4 追认 2.0.0 重冻结生成） |
| 时限初值 | 60 s |

### mixed · 混合复杂场景

| 项 | 内容 |
|---|---|
| 目的—测指标 | 指标 1~6；指标 7（动态应变）主场之一（综合压力） |
| 环境要素 | 直线路径 12±1 m；静态障碍 4~6 个（参数同 static_avoid）+ 动态行人 2 个（参数同 dynamic_pedestrian，逐行人独立抽样） |
| 随机化范围（20 实例） | 上述两场景随机化组合抽样 |
| 时限初值 | 75 s（估中位 ~45 s × 1.5 ≈ 68，留动态减速余量） |

## 指标映射摘要

指标 1~6 全场景适用；指标 7（动态应变）仅 `dynamic_pedestrian` + `mixed` 合并口径。详见 docs/指标定义.md「指标↔场景映射」。
